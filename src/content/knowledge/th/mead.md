# 🍯 Mead

<div class="article-lead">

Mead คือเครื่องดื่มหมักที่ทำจาก **น้ำผึ้ง น้ำ และยีสต์** เป็นหลัก หลายคนเรียกมันว่า "ไวน์น้ำผึ้ง" แต่ในทางปฏิบัติ Mead มีบุคลิกเป็นของตัวเอง และอาจออกมาได้ตั้งแต่นิ่งถึงซ่า แห้งถึงหวาน หรือเรียบง่ายไปจนถึงซับซ้อนมาก

แม้ Mead จะเป็นหนึ่งในเครื่องดื่มหมักที่เก่าแก่มาก แต่คำกล่าวที่ยิ่งใหญ่มาก ๆ เกี่ยวกับมันหลายอย่างก็พิสูจน์แบบตรงไปตรงมาได้ยาก สิ่งที่ชัดเจนกว่าคือมนุษย์ในหลายภูมิภาคค้นพบว่าน้ำผึ้งสามารถหมักได้ และพัฒนาออกมาเป็นเครื่องดื่มหลายรูปแบบ

</div>

---

## 🏯 ประวัติโดยย่อ

เครื่องดื่มหมักจากน้ำผึ้งหรือเครื่องดื่มที่มีน้ำผึ้งเป็นส่วนหนึ่ง ปรากฏในหลายอารยธรรมโบราณ:

- **จีนโบราณ** — มีหลักฐานทางโบราณคดีของเครื่องดื่มหมักที่มีน้ำผึ้งรวมอยู่กับวัตถุดิบอื่น
- **ยุโรปเหนือ** — Mead ปรากฏในตำนาน บทกวี และพิธีกรรม
- **โลกเมดิเตอร์เรเนียนโบราณ** — มีการรู้จักเครื่องดื่มหมักจากน้ำผึ้งในหลายรูปแบบ
- **ยุโรปยุคกลาง** — Mead ยังมีบทบาททั้งในครัวเรือนและในวัฒนธรรมชนชั้นสูงบางส่วน

ความเชื่อมโยงระหว่างคำว่า **"ฮันนีมูน"** กับ Mead เป็นเรื่องที่ถูกเล่าบ่อย แม้เส้นทางทางประวัติศาสตร์ของคำนี้จะไม่ได้ปิดประเด็นทั้งหมด แต่ก็สะท้อนความสัมพันธ์ระหว่างน้ำผึ้ง การแต่งงาน และการเฉลิมฉลองได้ดี

ในช่วงไม่กี่ทศวรรษที่ผ่านมา Mead ได้รับความสนใจมากขึ้นอีกครั้งจากผู้ผลิตสมัยใหม่ที่ทดลองกับผลไม้ เครื่องเทศ ฮอป การบ่มในถัง และระดับความหวานที่หลากหลาย

## 👅 รสชาติเป็นอย่างไร?

รสชาติของ Mead เปลี่ยนไปได้มากตามชนิดน้ำผึ้ง วิธีหมัก ระดับแอลกอฮอล์ ความหวาน และสิ่งที่เติมเพิ่มเข้าไป

<div class="taste-box">

### 🎨 ลักษณะ
- สีฟางอ่อนถึงอำพันเข้มหรือทอง
- ใสหรือขุ่นก็ได้
- นิ่ง ซ่าเล็กน้อย หรือซ่าเต็มที่ก็ได้

### 👃 กลิ่น
- **คาแรกเตอร์จากน้ำผึ้ง** — อาจออกดอกไม้ หวาน สมุนไพร หรือขี้ผึ้ง แล้วแต่แหล่งที่มา
- **ขึ้นอยู่กับสิ่งที่เพิ่ม** อาจมีผลไม้ เครื่องเทศ สมุนไพร ดอกไม้ ไม้ หรือฮอป
- การหมักสะอาด ไม่มีกลิ่นแปลก

### 👄 รสชาติ
- **รสน้ำผึ้ง** — แตกต่างตามแหล่งดอกไม้ (wildflower, orange blossom, clover ฯลฯ)
- **หวานถึงแห้ง** — ขึ้นอยู่กับน้ำตาลตกค้าง
- **โดยทั่วไปขมน้อย** — เว้นแต่มีฮอป เครื่องเทศ ไม้ หรือผลไม้ที่ให้แทนนินร่วมด้วย
- **รสผลไม้ เครื่องเทศ หรือสมุนไพร** — ถ้ามีการเพิ่ม
- จบท้ายอาจแห้ง คม กลม แทนนินชัด หรือเข้มข้นก็ได้ แล้วแต่สไตล์

### ✨ ความรู้สึก
- **บอดี้เบาถึงเต็ม** — แตกต่างกันมาก
- นิ่ง ซ่าเล็กน้อย หรือซ่าเต็มที่
- บางชนิดมีแทนนินเล็กน้อย (จากผลไม้หรือการบ่ม)

</div>

## 🍶 ประเภทของ Mead

| ประเภท | คำอธิบาย |
|---|---|
| **Traditional Mead** | น้ำผึ้ง น้ำ ยีสต์ — เน้นคาแรกเตอร์ของน้ำผึ้งเป็นหลัก |
| **Melomel** | Mead ผสมผลไม้ (เบอร์รี่ เชอร์รี่ ซิตรัส ฯลฯ) |
| **Metheglin** | Mead ผสมเครื่องเทศหรือสมุนไพร (อบเชย ขิง วานิลลา) |
| **Bochet** | Mead จากน้ำผึ้งคาราเมล — รสลึก หอมคั่ว |
| **Cyser** | Mead ผสมแอปเปิล (คล้ายน้ำผึ้ง + ไซเดอร์) |
| **Pyment** | Mead ผสมองุ่น (คล้ายน้ำผึ้ง + ไวน์) |
| **Hydromel** | Mead แอลกอฮอล์ต่ำ — เบาและมักสดชื่นกว่า |
| **Sack Mead** | Mead แอลกอฮอล์สูง — มักเข้มข้นและเต็มกว่า |
| **Braggot** | Mead ผสมมอลต์ — ลูกผสมระหว่าง Mead และเบียร์ |
| **Hopped Mead** | Mead ที่ผ่านการ dry-hop เหมือน IPA |

## 🍯 น้ำผึ้ง: หัวใจของ Mead

ชนิดของน้ำผึ้งเป็นหนึ่งในปัจจัยที่ส่งผลต่อรสชาติมากที่สุด:

| แหล่งน้ำผึ้ง | รสชาติ |
|---|---|
| **Orange Blossom** | เบา หอมซิตรัส ดอกไม้ |
| **Wildflower** | ซับซ้อน เอิร์ธโทน ดอกไม้ |
| **Clover** | อ่อน หวาน สะอาด |
| **Buckwheat** | เข้ม เหมือนกากน้ำตาล เอิร์ธโทน |
| **Manuka** | สมุนไพร เข้มข้น |
| **Acacia** | เบามาก ละเอียดอ่อน ดอกไม้ |

## 🍽️ อาหารที่เข้ากัน

Mead จับคู่กับอาหารได้กว้าง แต่ผลลัพธ์ขึ้นอยู่มากกับระดับความหวาน ความซ่า และสิ่งที่อยู่ในสูตร

| ประเภท Mead | อาหารที่เข้ากัน |
|---|---|
| **Traditional แห้ง** | ชาร์คูเตอรี ชีสอ่อน ไก่ย่าง |
| **Traditional หวาน** | บลูชีส ทาร์ตผลไม้ ครีมบรูว์เล |
| **Melomel (เบอร์รี่)** | ดาร์กช็อกโกแลต เนื้อย่าง ขนมเบอร์รี่ |
| **Melomel (ซิตรัส)** | ซีฟู้ด สลัด อาหารรสจัด |
| **Metheglin (เครื่องเทศ)** | หมูอบ เครื่องเทศ เค้ก |
| **Hopped Mead** | เบอร์เกอร์ ของทอด อาหารเผ็ด |
| **Braggot** | BBQ ชีสแก่ สตูว์ |

## 💡 เคล็ดลับการดื่ม

- **อุณหภูมิสำคัญ** — mead เบามักเหมาะกับอุณหภูมิที่เย็นกว่า ส่วนตัวที่แรงหรือเข้มขึ้นมักเปิดกลิ่นได้ดีเมื่ออุ่นขึ้นเล็กน้อย
- **ให้เวลา mead ที่แรงขึ้นสักนิด** — โดยเฉพาะตัวที่แอลกอฮอล์สูงหรือผ่านการบ่ม
- **จับคู่ตามสไตล์ ไม่ใช่ตามชื่อรวม** — traditional แห้ง, melomel หวาน, หรือ braggot อาจให้ประสบการณ์ต่างกันมาก
- **อย่าคาดหวังให้มันเหมือนเบียร์หรือไวน์เป๊ะ ๆ** — Mead มีสมดุลของน้ำผึ้ง กรด แทนนิน และแอลกอฮอล์ในแบบของตัวเอง
- **Mead ซ่าเหมาะกับบางโอกาสคล้าย sparkling wine** — แต่ก็ยังเป็นสไตล์ของมันเอง ไม่ใช่ของแทนตรงตัว
