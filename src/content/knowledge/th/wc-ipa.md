# 🌊 WC IPA (West Coast IPA)

<div class="article-lead">

WC IPA — West Coast IPA — เป็นหนึ่งในตัวแทนชัดที่สุดของการต้มเบียร์สายฮอปแบบอเมริกัน โดยทั่วไปมันโดดเด่นด้วย **ความใส ความขมที่คม และกลิ่นฮอปชัดเจน** ซึ่งมักไปทางสน ซิตรัส ยางไม้ และจบท้ายแห้ง

ถ้า Hazy IPA มักให้ความนุ่มและผลไม้เด่น WC IPA ก็มักให้ภาพที่ **ใสกว่า แห้งกว่า และขมคมกว่า**

</div>

---

## 🏯 ประวัติโดยย่อ

West Coast IPA เริ่มเป็นรูปเป็นร่างชัดขึ้นในช่วงทศวรรษ 1970–80 เมื่อผู้ผลิตเบียร์อเมริกันเริ่มผลักการใช้ฮอปให้เด่นขึ้น โดยเฉพาะฮอปจากแปซิฟิกนอร์ธเวสต์ เมื่อเทียบกับ IPA แบบอังกฤษหลายสาย เบียร์เหล่านี้มักมุ่งไปทางความขมที่คมกว่า กลิ่นฮอปที่ชัดกว่า และมอลต์ที่สะอาดกว่า

ผู้บุกเบิกอย่าง **Sierra Nevada (Pale Ale)** , **Anchor Brewing (Liberty Ale)** และต่อมา **Stone Brewing** กับ **Russian River** ช่วยสร้างภาพจำของสไตล์นี้ จนในช่วงปี 1990–2000 West Coast IPA กลายเป็นหนึ่งในรูปแบบ IPA ที่ทรงอิทธิพลที่สุดของคราฟต์เบียร์ยุคใหม่

ชื่อ "West Coast" มาจาก **ฝั่งตะวันตกของสหรัฐอเมริกา** — โดยเฉพาะแคลิฟอร์เนีย ออริกอน และวอชิงตัน

## 👅 รสชาติเป็นอย่างไร?

<div class="taste-box">

### 🎨 ลักษณะ
- **ใสแจ๋ว** — มักใสและคมในภาพรวม
- สีทองถึงอำพันอ่อน
- ฟองขาวแน่น อยู่ได้ดี

### 👃 กลิ่น
- **ยางไม้ (Pine)** — กลิ่นสนสดหรือเรซินแบบป่าสน
- **ซิตรัส** — เกรปฟรุต เปลือกส้ม มะนาว
- **Resin** — กลิ่นฮอปแนวเหนียว ดิบ หรือ dank ได้บ้าง
- **มอลต์สะอาด** — ขนมปังหรือแครกเกอร์ โดยทั่วไปไม่เน้นคาราเมลหวาน
- คาแรกเตอร์จากการหมักมักถูกกดไว้ไม่ให้เด่น

### 👄 รสชาติ
- **ความขมชัดเจน** — มักอยู่ราว 50–70+ IBU และให้ความรู้สึกคมกว่า IPA สายที่นุ่มกว่า
- **รสฮอปสน ซิตรัส** — เป็นลายเซ็นสำคัญ
- **มอลต์สะอาด** — รองรับฮอปโดยไม่ขึ้นมานำ
- **คาแรกเตอร์ crystal/caramel malt ต่ำ** — โดยเฉพาะในเวอร์ชันสมัยใหม่
- **จบท้ายแห้ง** — ความขมมักค้างชัดเจนพอสมควร

### ✨ ความรู้สึก
- **บอดี้ปานกลาง** — ไม่บางไม่หนัก
- **กรอบ สะอาด** — มักมาจากการหมักที่แห้ง และบางสูตรอาจมีการใช้น้ำตาลอย่างพอเหมาะ
- คาร์บอนปานกลาง
- **จบท้ายแห้ง** — ทำให้ดื่มได้เรื่อย ๆ ทั้งที่ขม

</div>

## 🍶 West Coast vs Hazy IPA

| ด้าน | WC IPA (West Coast) | Hazy IPA (NE Style) |
|---|---|---|
| ลักษณะ | ใสแจ๋ว | ขุ่นทึบ |
| ความขม | สูง คม (50–70+ IBU) | ต่ำ นุ่ม (30–50 IBU) |
| กลิ่นฮอป | ยางไม้ สน เกรปฟรุต | ผลไม้เมืองร้อน juicy |
| มอลต์ | สะอาด ประคอง | นุ่ม โอ๊ตตี้ |
| บอดี้ | ปานกลาง กรอบ | ปานกลางถึงเต็ม ปุยนุ่ม |
| จบท้าย | แห้ง ขม | กึ่งแห้ง ผลไม้ |

## 🌲 ฮอปอเมริกัน

West Coast IPA ถูกกำหนดโดยสายพันธุ์ฮอปอเมริกัน:

| ฮอป | รสชาติ |
|---|---|
| **Cascade** | เกรปฟรุต ดอกไม้ — คลาสสิก |
| **Centennial** | มะนาว สน กลมกล่อม |
| **Chinook** | สน เครื่องเทศ จัดจ้าน |
| **Simcoe** | สน เอิร์ธโทน เสาวรส |
| **Citra** | เมืองร้อน ซิตรัส เข้มข้น |
| **Amarillo** | ส้ม ดอกไม้ หวาน |
| **Mosaic** | เบอร์รี่ เมืองร้อน ซับซ้อน |

## 🍽️ อาหารที่เข้ากัน

ความขมที่คมของ WC IPA มักเข้ากับอาหารมัน เผ็ด และรสเข้มได้ดี

| เมนู | ทำไมถึงเข้ากัน |
|---|---|
| 🍔 **เบอร์เกอร์** | ความขมตัดกับความมันของเนื้อ |
| 🌮 **ทาโก้** | ฮอปซิตรัส เข้ากับซัลซ่าและมะนาว |
| 🧀 **เชดดาร์แก่** | ฮอปสู้กับความเข้มของชีส |
| 🐖 **BBQ ซี่โครงหมู** | หวานรมควัน + ขม = มหัศจรรย์ |
| 🍟 **ของทอด** | คาร์บอนและความขมตัดน้ำมัน |
| 🌶️ **อาหารรสจัด** | ความขมช่วยบาลานซ์ความเผ็ด |

## 💡 เคล็ดลับการดื่ม

- **เสิร์ฟเย็นกำลังดี** — 8–12°C ช่วยให้กลิ่นฮอปแสดงชัดกว่าเสิร์ฟเย็นจัด
- **ความสดสำคัญ** — กลิ่นฮอปเปลี่ยนไปตามเวลา โดยเฉพาะแบบบรรจุ
- **กินกับอาหารรสจัดได้ดี** — ความขมและความแห้งช่วยรับมือรสเข้มได้
- **เหมาะกับคนที่ชอบความขมแบบมีโครงสร้าง** — โดยเฉพาะเมื่อเทียบกับ IPA สายที่นุ่มกว่า
- **ลองเทียบกับ Hazy IPA** — จะเห็นความต่างเรื่องความขม ความใส และสัมผัสได้ชัดมาก
